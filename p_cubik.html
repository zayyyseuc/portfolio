Spatial UX · Remote collaboration · Unreal Engine 5 + Meta Quest

CUBIK

A VR workspace where each person owns a cube — one face for each mode of work — so collaborating means handing over space, not taking someone’s time.

Challenge
Remote work runs on synchronous meetings and folder logic built for flat screens, and VR offices have copied both.
Insight
In space, people find things by place and by body, not by paths and permissions.
Result
A working Quest build with gravity-adaptive navigation, files you can grab, and menus projected onto each surface.

Remote work keeps growing, but no VR office has found its premise.

Big-platform attempts like Microsoft Mesh have been retired. The gap isn’t hardware, it’s a product model that still assumes everyone meets at the same time.
