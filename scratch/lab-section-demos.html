Design Lab — Grid Treatment

Four ways to cut the corners

Same seven tiles, same bento spans, same content — only the edge treatment changes. The current build uses a 16px radius on every tile, which is what's reading heavy. Each option below removes or rethinks that.

A

Hairline grid

Sharp corners, 1px gap doubling as a rule between every tile. No radius, no shadow — reads like a contact sheet.
